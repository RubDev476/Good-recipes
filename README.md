# Good recipes
Sitio web de catalogo de recetas para comidas, postres, desayunos y cockteles.

![App Screenshot](/hero.png)

## 🚀 Demo
https://good-recipes-vert.vercel.app/

## 🎨 Mockups y Diseño
https://www.figma.com/design/YWFxZZFUbPjIjLUyxVzRxR/Good-Recipes?node-id=21-471&t=BkMhg2LAN4KhqdYw-1

## 🛠️ Stack
- React 19 con Vite
- React Router DOM
- Styled Components
- Zod
- Figma
- APIS: [The CocktailDB](https://www.thecocktaildb.com/) | [The MealDB](https://www.thecocktaildb.com/)

## ✨ Características principales
- 🕒 **Página principal con slider dinámico**: muestra recetas de desayuno, comida y cócteles según la hora real.  
- 🍹 **Página de categorías de cócteles (Cocktails)**: shot, café, cítricos, etc.  
- 🍗 **Página de categorías de comidas (Meals)**: chicken, beef, etc.  
- 📄 **Página individual de receta**: detalle completo de cada receta seleccionada.  
- 🔗 Navegación con **React Router DOM**.  
- ✅ Validaciones con **Zod**.  
- 🎨 Estilos con **Styled Components**.  
- 📱 Diseño responsivo y moderno.  
- 📱 Mockups con Figma.
